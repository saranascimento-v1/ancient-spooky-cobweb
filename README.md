💰 Sistema Bancário em Python (CLI)

Um sistema bancário simples desenvolvido em Python, executado via terminal (CLI), que simula operações essenciais de uma instituição financeira, como criação de usuários, contas, depósitos, saques e consulta de extrato.

🚀 Funcionalidades

✔️ Cadastro de usuários
✔️ Criação de contas bancárias
✔️ Depósitos com validação
✔️ Saques com regras de limite
✔️ Controle de limite diário de saques
✔️ Geração de extrato detalhado
✔️ Interface interativa via terminal

🧠 Regras de Negócio
Limite de saque por operação: R$ 500,00
Limite de saques diários: 3 saques
Não permite:
Saques sem saldo
Valores negativos
Cadastro duplicado de CPF

📌 Sobre o Projeto

Este projeto foi desenvolvido com foco em aprendizado e prática de conceitos fundamentais de programação em Python, simulando operações bancárias reais de forma simples e eficiente.
